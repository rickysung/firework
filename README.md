# 한강의 밤 · Fireworks on the Han

기존 Canvas 2D 불꽃놀이를 Three.js / WebGL 2 기반의 3D 장면으로 확장했습니다. 한강에서 영감을 받은 절차적 도시이며, 실제 서울 지형을 재현한 모델은 아닙니다.

## 실행

Node.js 22.12 이상이 필요합니다.

```sh
npm install
npm run dev
```

터미널에 표시되는 로컬 주소를 여세요. `index.html`을 파일로 직접 여는 방식은 지원하지 않습니다.

```sh
npm run build
npm run preview
```

배포 시 `dist/` 내용을 정적 호스팅에 올립니다. 상대 경로 빌드이므로 `/firework/` 같은 하위 경로도 지원합니다. 기존 Jekyll 소스 배포 방식에서는 먼저 Vite 빌드를 수행하도록 배포 설정을 바꿔야 합니다. 실행에 외부 CDN, 이미지, 폰트, API 키는 필요하지 않습니다.

## 장면과 조작

- 강 위 580 m 길이의 일렬 플랫폼과 9개 발사 지점. 상승탄은 각 발사 지점에서 출발합니다. 발사대 프로그램은 부채꼴, 수직 연발, 교차 발사, 좌우로 흐르는 코멧 중에서 선택할 수 있습니다. 자동 모드는 매 시퀀스마다 프로그램을 바꾸며, 각 프로그램 안에서도 발사 순서·각도·분출 시간을 조절합니다.
- 프로그램을 구형 합주, 다중 코어 겹구형, 황금 커튼, 갤럭시로 통합했습니다. 구형은 5~6발씩 4회, 겹구형은 3~4발씩 4회, 황금 커튼은 4발씩 4회 동시 발사합니다. 자동 공연은 구형과 겹구형에 높은 비중을 주고, 스마일·야자수·분열은 드문 장식으로만 섞습니다. A–Z, 0–9 글자 경로와 `?text=SEOUL+2026`도 지원합니다.
- 강변, 고층 빌딩, 느리게 순환하는 헬리콥터 시점. 시점 사이를 부드럽게 전환합니다.
- 물결 / 반사 흐림, Bloom, 보케, 수동 초점 / 자동 초점, 화질, 글자 불꽃을 설정할 수 있습니다.
- `1` / `2` / `3`: 시점, `Space`: 재생 / 정지, `F`: UI를 숨기는 몰입 모드, `Esc`: 돌아가기.
- OS의 동작 줄이기가 켜져 있으면 정지 상태로 시작합니다. 탭이 숨겨지면 공연 시간이 멈춥니다.

## 렌더링

`src/choreography.js`는 불꽃의 형상과 공연 순서를 구성합니다. 시간 단위는 초, 공간 단위는 m입니다. 동시 발사 묶음을 여러 차례 이어가며, 색과 높이·깊이를 바꿉니다. 상승탄마다 비행 시간과 3차원 경로가 다르고, 비행 시작 시간순으로 별도 예약합니다. 예전 원본은 `js/fireplay.js`에 남아 있습니다.

`src/pyrotechnics.js`는 재현 가능한 시드로 불꽃별 입자를 생성합니다. 구면 위도 격자를 없애고 구면 전체에 균일하게 점을 배치합니다. 원형 계열은 질량 편차 ±5%, 초기 속도 편차 약 ±1.2%로 매끈한 구형 외곽을 유지하고, 주된 변화는 연소·잔광·색상·시퀀스에 줍니다. 야자수·분열 계열은 가지 형태를 사용합니다. 국화는 약 1,300개 입자, 갤럭시는 약 32초 동안 4,200~4,600회 폭발을 이어가며 각각 약 130개 입자로 구성하고, 겹구형은 이중·삼중·지연 점화·황금 코어·위성 구형의 5가지 변형을 사용합니다. 코어는 모체 중심의 중력 이동을 따라가며 서로 다른 크기와 색으로 펼쳐집니다. 입자마다 질량에 따른 저항, 연소 수명, 잔광 지속 시간, 크기, 밝기, 색상 변이, 반짝임 위상이 다릅니다. 질량은 공기 저항에 영향을 주며 중력 가속도 자체는 동일합니다. 선형 저항과 중력의 해석해에 바람과 약한 흔들림을 더합니다. 분열 불꽃은 모체의 실제 이동 위치·속도에서 생성되며, 대형 불꽃은 지연된 내부 코어를 함께 터뜨립니다.

`src/fireworks.js`는 이 입자 데이터를 GPU에 업로드합니다. 시간차를 둔 잔광이 연소 입자의 궤적을 따라가면서 바람과 중력으로 흩어지고 주황색으로 식습니다. 반사·컬러·깊이 패스가 같은 궤적 코드를 공유합니다. 사용이 끝난 geometry / material을 해제하고 최대 420개 폭발, 580,000개 잔광 포함 정점, 48개 상승탄으로 자원을 제한합니다. 마지막 일제 발사 직후 다음 시퀀스의 상승탄을 준비합니다. 기존 잔광과 예약된 자식 폭발은 각자의 수명이 끝날 때까지 계속 렌더링하므로, 전환 때 불꽃을 지우거나 모든 잔광이 사라질 때까지 기다리지 않습니다. 갤럭시는 좌우 약 1.2 km, 높이 110–450 m, 깊이 약 580 m 영역에 불꽃을 분산하며, 발사대 프로그램도 8초 간격으로 이어집니다.

`src/environment.js`는 인스턴싱한 건물, 가로등, 양방향 차량, 사장교와 발사대를 구성합니다. 별, 창문, 연기는 코드로 생성합니다. 수면은 반사 카메라와 clip plane을 사용하는 planar reflection을 사용합니다. `src/water-shader.js`에서 저주파 굴곡, 서로 다른 방향으로 흐르는 중간 파도와 잔물결, domain warping을 조합해 불규칙한 법선을 만듭니다. 지점별 거칠기에 따른 9회 원반 샘플링과 법선 기반 Fresnel을 적용하고, 멀리 있는 미세 물결은 픽셀 크기에 맞춰 줄여 깜빡임을 방지합니다. 이 방식은 화면 밖의 불꽃도 반사할 수 있습니다.

`src/postprocessing.js`는 GPU 입자의 실제 위치를 반영하는 전용 depth material로 깊이를 렌더링합니다. Three.js의 원형 다중 샘플 Bokeh shader로 피사계 심도를 적용한 다음 Bloom, ACES tone mapping, sRGB 출력을 수행합니다. 자동 초점은 카메라에서 불꽃 중심까지의 시선 방향 거리를 사용합니다.

기술 참고: [Three.js post-processing](https://threejs.org/manual/en/post-processing.html), [BokehPass / Bokeh shader](https://threejs.org/docs/pages/BokehPass.html), [Reflector](https://threejs.org/docs/pages/Reflector.html).

## 검증

```sh
npm test
npm run test:browser
```

브라우저 테스트는 설치된 Google Chrome을 사용합니다. 입자별 분산과 시드 재현성, 물리 궤적, 모체에서 분열되는 위치 / 속도, 자원 해제, 시퀀스 개수 / 종료 시간, 발사대 정렬, 글자 보존, WebGL 오류, 카메라 / 설정 / 재생 / 모바일 레이아웃 / 동작 줄이기 기능을 검사합니다.

화질 프리셋은 화면 pixel ratio와 반사 render target의 해상도를 조절합니다. 고해상도 화면에서 속도가 부족하면 '성능 우선'을 선택하거나 보케를 줄이세요. WebGL 2와 하드웨어 가속이 필요합니다. 수면은 실시간 평면 반사 근사이며, 연기는 볼륨 시뮬레이션 대신 반투명 sprite를 사용합니다.
